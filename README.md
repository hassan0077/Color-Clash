# Color Clash (Stroop Effect Game)

An engaging and modern Android game built with **Jetpack Compose** and **Material 3**, based on the psychological Stroop effect.

## 🚀 Features
- **Modern UI/UX**: Built entirely using Jetpack Compose and Material 3 design principles.
- **Game Logic**: Fast-paced Stroop effect challenge testing cognitive flexibility and reaction time.
- **Splash Screen & Smooth Navigation**: Polished animations and state management using ViewModels and Coroutines.

## 🛠️ Tech Stack
- **Language**: Kotlin
- **UI Framework**: Jetpack Compose, Material 3
- **Architecture**: MVVM (ViewModel, StateFlow)
- **Min SDK**: 24
- **Target SDK**: 37

## 📱 Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/color-clash.git
   ```
2. Open the project in **Android Studio**.
3. Sync Gradle and run the app on an emulator or physical device.
